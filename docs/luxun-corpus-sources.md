# 鲁迅语料来源、现有成果与补全路线

核查日期：2026-10-22。目标是为 Bible_talking 提供有篇名、有出处、可查看上下文的原文，避免只收集网络“鲁迅语录”。

## 已落地的文件

- 导入文件：`examples/corpora/lu-xun/`，按原文集名分成30个 UTF-8 JSONL，41,832段、2,887,007字符。
- 使用说明：`examples/corpora/lu-xun/README.md`。
- 来源、计数与哈希：`resources/lu-xun/manifest.json`。
- 2,916个源目录条目的定位：`resources/lu-xun/sections.json`。
- 2,523个保留文本单元及源文件字符范围：`resources/lu-xun/works.json`；另有便于查看的 `catalog.csv`。
- 排除与待校勘位置：`resources/lu-xun/excluded.json`。
- 解析验证报告：`resources/lu-xun/verification.json`。

源文本按网页自称的2005年版18卷结构组织。本批从第1—16卷提取内容，第17卷的现代人物书刊注释、第18卷的年表和索引不进入鲁迅原文库。原始下载缓存15,495,990字节，含正文和编注等，共5,824,268字符；这个数字不是鲁迅原创正文数量。

## 尚需补全的材料

1. **第14卷致外国人士书信。** 当前排除了该部分及其附录，共118个目录条目。需要区分鲁迅所写外文、他人中译文、答问中的提问者、联合署名文字，再确定如何进入不同语料库。目录已保留，可从[第14卷](https://doosho.com/cn/116/14)逐项继续。
2. **13个损坏段落。** 涉及部分书信、诗文以及1932、1936年日记。仅排除损坏段落，同篇其余部分已保留；不得凭模型猜测补字。优先找可靠纸本或旧版影像对校。
3. **《两地书》的他人来信及合写内容。** 当前67个目录条目列为他人或待核。保留的鲁迅信件按称谓、署名及少数人工核对的例外筛选；仍应复核。若扩展为往来信资料库，应逐封/逐段署名，不能全部挂在鲁迅名下。
4. **鲁迅译作。** 可从[月界旅行](https://zh.wikisource.org/wiki/月界旅行)、[死魂灵](https://zh.wikisource.org/wiki/死魂靈)以及作者页中的《地底旅行》《现代日本小说集》《俄罗斯的童话》等入口开始。须同时记原作者与译者；2005年18卷本的《译文序跋集》只是序跋，不能替代译作全文。
5. **辑录古籍。** [古小说钩沈](https://zh.wikisource.org/wiki/古小說鉤沈)、作者页中的《会稽郡故书杂集》《嵇康集》及旧版第8—10卷是入口。古人正文、鲁迅辑校及序跋应分开标记。
6. **早期科学著述、手稿及新发现佚文。** 《中国矿产志》《人生象敩》等需另找可靠底本；2005年版[出版说明](https://doosho.com/cn/116/1)也明确把译文、辑录古籍及部分科学著作另行处理。本次没有为这些材料声称已完成下载或转录。

## 清洗与验收边界

清洗按源目录逐项定位；排除编者导言与集中注释，去掉数字脚注锚点，按原段落输出。不繁简转换、不改写、不补字。保留目录层级、源网址和源文件字符范围，另存SHA-256供追溯。完全相同的文本单元进行了去重检查，本次未发现完全相同单元；改写版、摘录版及跨篇重复引语仍可能存在。

全部30个文件通过项目 `backend.parsers.parse_upload`，42,998个解析片段的字符位置逐条核对通过。逐段核对产出与源文本经声明清洗后的一致性；三部小说集的14+11+8篇标题齐备，年度日记25个单元齐备，其中1922年明确为断片。这些检查证明格式和转录链路一致，不能代替与纸本的逐字校勘。

不同来源的许可声明不能互相替代。尤其现代注释、他人的翻译以及研究文章不能仅因置于“鲁迅全集”目录中就认定是鲁迅的公版原创。篇内人物对白、引文、编译材料也不等于作者本人的立场。此批适合作为可追溯的检索起点，正式引用仍需核查篇章上下文与版本。

此次没有修改前端、数据库或已有语料，没有运行模型索引。前端预览和构建要求未被触发。
